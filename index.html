Command Index

01

Leadership & Command

HIGH COMMAND // VC

Vanguard Commander

Holds the highest authority within Osiris Vanguard. Oversees faction leadership, long-term direction, and major organizational decisions.

HIGH COMMAND // VHC

Vanguard High Command

Assists the Vanguard Commander and coordinates high-level command responsibilities and administration.

HIGH COMMAND // CMD

Commander

Directs faction activities, supervises command personnel, and ensures that organizational standards and directives are properly maintained.

OFFICER CORPS // OPS

Operations Officer

Coordinates operational planning, mission preparation, execution, and communication between personnel.

COMMAND STAFF // CS

Command Staff

Supports command administration, personnel coordination, and the implementation of faction directives.
